# UK Bank Customer Analysis Dashboard (Tableau)

This project presents an interactive Tableau dashboard analyzing customer data from a UK bank dataset. The dashboard provides insights into account balances, demographic distribution, transactions, and customer segmentation.
# project Description
 Distribution of Account Balance
Visualizes how customer balances are distributed across different ranges.

Balance by Surname
Identifies surname categories with the highest total account balances.

Job Category Analysis (Tree Map)
Displays customer segmentation based on job types such as yellow Collar, Green Collar, and Others.

 Gender Distribution (Pie Chart)
Shows the proportion of male and female customers.

 Age vs Transaction Distribution
Analyzes how transactions vary across different age groups.

# Tools Used:

Tableau Public

UK Bank Dataset (Excel)

🎯 Objective:

To analyze customer financial behavior, demographic patterns, and balance distribution using interactive visual analytics for better business insights and decision-making.

# Project Description:
This project presents an interactive Tableau dashboard that analyzes movie ratings across different genres and years. The dashboard provides insights into rating trends, audience preferences, and the relationship between critic and audience scores.

Movie Rating Trend Over Time
Analyzes how Rotten Tomatoes ratings have changed across different release years.

Distribution of Ratings by Genre
Visualizes how audience ratings are distributed across various movie genres.

Genre-wise Movie Share (Pie Chart)
Shows the proportion of movies in each genre category.

Average Rating by Genre
Compares the average Rotten Tomatoes ratings across genres to identify top-performing categories.

Correlation Analysis (Scatter Plot)
Examines the relationship between Rotten Tomatoes ratings and Audience ratings to identify patterns and trends.

# Tools Used

Tableau Public

Movie Ratings Dataset

🎯 Objective
To explore movie performance patterns, analyze genre-based rating differences, and understand the relationship between critic reviews and audience feedback using visual analytics.

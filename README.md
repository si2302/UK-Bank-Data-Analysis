# UK Bank Customer Analysis Dashboard (Tableau)

This project presents an interactive Tableau dashboard analyzing customer data from a UK bank dataset. The dashboard provides insights into account balances, demographic distribution, transactions, and customer segmentation.

🔍 Key Insights Covered:

 Distribution of Account Balance
Visualizes how customer balances are distributed across different ranges.

Balance by Surname
Identifies surname categories with the highest total account balances.

Job Category Analysis (Tree Map)
Displays customer segmentation based on job types such as yellow Collar, Green Collar, and Others.

 Gender Distribution (Pie Chart)
Shows the proportion of male and female customers.

 Age vs Transaction Distribution
Analyzes how transactions vary across different age groups.

# Tools Used:

Tableau Public

UK Bank Dataset (Excel)

🎯 Objective:

To analyze customer financial behavior, demographic patterns, and balance distribution using interactive visual analytics for better business insights and decision-making.
